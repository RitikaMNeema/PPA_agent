PPA_agent

AI agent and Bayesian optimisation improving the power, performance and area of a RISC-V core (PicoRV32, sky130) on an open-source ASIC flow, with flow runs distributed on Spark. These are static snapshots of the project's dashboards. Source and write-up: GitHub repository.

Flow dashboard →
Every flow run: area, timing, power, stage status, and links to logs and reports. Exploration & agent →
Bayesian-optimisation sweep run on Spark (surrogate accuracy, knob relevance, Pareto front) and the closed-loop agent's step-by-step decisions. Bottlenecks & RTL suggestions →
Top power, timing and congestion bottlenecks traced to RTL lines, with suggested RTL patches as diffs.

Snapshot generated 2026-11-26. The Generate and Run buttons only work with the local server (python flow/serve.py).
